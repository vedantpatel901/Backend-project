# ✈️ Airline Booking System - Backend

A backend project for an Airline Booking System built using Node.js, Express.js, MySQL, and Sequelize ORM.

The project focuses on developing REST APIs and backend services for managing airline-related data such as cities, airports, airplanes, and flights.

This project is currently under active development as I continue learning and implementing backend development concepts, database management, REST API design, and Sequelize ORM.
